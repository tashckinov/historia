# Historia — Telegram бот геополитической AI-игры

Бот реализует игровой цикл:
1. `/start` → выбор: начать новую игру или открыть существующую сессию (если сессии есть).
2. Для новой сессии: выбор единственного режима `Историческая симуляция (с 27.08.2025)` с фиксированной инструкцией исторического сценария.
3. Автозагрузка моделей из Ollama (`/api/tags`) и выбор модели кнопками.
4. Выбор страны (рус/англ).
5. Ход игрока:
- Действия игрока проходят базовую валидацию: нельзя оформлять договоры от имени третьих стран или напрямую менять границы/территории между чужими странами.
- В промпте генерации мира используется протокол `intent / feasibility / outcome`, чтобы невозможные действия не считались свершившимися фактами.
   - до 15 действий,
   - диалоги с государствами/блоками (ЕС, НАТО, ООН, БРИКС и т.д.),
   - консультация с AI-советником.
6. `Конец хода` → выбор периода перемотки.
7. Ollama получает все действия и диалоги за период и возвращает 1–15 новостных «статей» (заголовок + описание).
8. Кнопка `🛑 Завершить сессию` вынесена в Keyboard button (клавиатура чата) — после неё снова показывается выбор: новая игра или список сессий.
8. При выборе существующей сессии доступны кнопки: `Продолжить`, `Переименовать`, `Удалить`.

## Подключение к Ollama
- В обычной Linux/macOS среде: по умолчанию `http://localhost:11434`.
- В WSL: бот автоматически использует IP Windows-хоста из `/etc/resolv.conf`, то есть запросы идут на `http://<WIN_IP>:11434`.
- Можно переопределить вручную через переменную:
  - `OLLAMA_BASE_URL=http://<host>:11434`
  - `OLLAMA_REQUEST_TIMEOUT=180` (таймаут ответа Ollama в секундах, по умолчанию 120)

Проверка из WSL:

```bash
WIN_IP=$(grep -m1 nameserver /etc/resolv.conf | awk '{print $2}')
curl "http://$WIN_IP:11434/api/tags"
```

## Требования
- Запущенный Ollama на хосте, доступный из окружения бота.
- Установленная хотя бы одна модель (например, `qwen3:8b`).


## Сохранение прогресса
- Прогресс сохраняется в SQLite по сессиям (`historia.sqlite3` по умолчанию).
- У одного пользователя может быть несколько сессий; можно переключаться между ними через `/start`.
- После перезапуска бота, а также после блокировки/разблокировки, все сессии сохраняются.
- Состояние мира (`WorldState`: владение регионами, войны, перемирия) хранится по каждой сессии в SQLite и передаётся в промпт генерации как краткий срез для страны игрока.
- `/newgame` создаёт новую сессию и делает её активной.
- Путь к БД можно переопределить: `HISTORIA_DB_PATH=/path/to/historia.sqlite3`.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
export TELEGRAM_BOT_TOKEN="..."
# опционально, если нужно принудительно задать адрес Ollama:
# export OLLAMA_BASE_URL="http://<host>:11434"
python -m historia_bot.bot
```


### Быстрый разворот окружения на Windows (PowerShell)

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e .
$env:TELEGRAM_BOT_TOKEN="<your_token>"
# опционально:
# $env:OLLAMA_BASE_URL="http://localhost:11434"
# $env:OLLAMA_REQUEST_TIMEOUT="180"
python -m historia_bot.bot
```

## Структура
- `src/historia_bot/game.py` — состояние игры, лимиты, сбор промпта.
- `src/historia_bot/ai.py` — интеграция с Ollama API (`/api/tags`, `/api/chat`) и выбор адреса для WSL/host.
- `src/historia_bot/bot.py` — Telegram-обработчики и игровой процесс.
- `tests/test_game.py` — базовые тесты логики.
- `tests/test_ai.py` — тесты определения WSL и IP Windows-хоста.
